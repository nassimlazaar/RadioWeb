RadioWeb 📻

RadioWeb est une application Android moderne et épurée permettant d'écouter les stations de radio en direct, gratuitement et sans création de compte. Elle est optimisée pour une utilisation fluide sur smartphone et en voiture grâce à son intégration Android Auto.

🌟 Fonctionnalités

  • 🎧 Écoute en direct : Accès instantané aux flux de streaming radio.
  • 🚗 Compatible Android Auto : Contrôlez vos radios directement depuis l'écran de votre véhicule.
  • 🚀 Sans inscription : Aucun compte requis, accès direct au contenu.
  • 📱 Lecture en arrière-plan : Contrôle de la lecture via les notifications et l'écran de verrouillage.
  • ⚡ Légère et rapide : Interface optimisée pour une faible consommation de ressources et de batterie.

🛠️ Fiche technique

  • Package Name : com.nassimlazaar.radioweb
  • Plateforme : Android (API 21+)
  • Langage / Environnement : Android SDK / Java / Kotlin
  • Services intégrés : Android Auto Integration, Google AdMob (SDK Publicité)

🚀 Configuration & Déploiement

Prérequis

  • Android Studio (dernière version recommandée)
  • JDK 17+
  • Android SDK (API Target 34+)
